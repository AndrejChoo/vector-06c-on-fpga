Проект создан в развлекательных целях, не является потактовым клоном оригинального компьютера, скорее является "Вектор" совместимым функциональным аналогом реализованным в FPGA. Позволяет прикоснуться к "Вектору" с помощью недорогих плат с FPGA, типа Cyclone 4, Cyclone 10LP, Xilinx Spartan 6 с минимальной дополнительной обвязкой.

Сердцем компьютера является HDL модель КР580ВМ80А от vslav: https://github.com/1801BM1/vm80a. Он работает на оригинальной частоте 3MHz.

Видеоадаптер реализован на двухпортовой синтезируемой блочной памяти FPGA, что ограничивает использование FPGA с малым объёмом встроенных блоков памяти, так как нужно синтезировать 32Кб (например, Altera Cyclone4 нужен минимум EP4CE10). Вывод изображения - по HDMI. Режим HDMI выбран 800х600х56Hz. Так как частота кадров в "Векторе" равна 50 герцам и с такой же частотой вызывается прерывание процессора, пришлось уменьшить частоту тактирования HDMI с 36MHz до 34MHz, чтобы приблизить частоту кадров к оригинальной (хотя и при такой частоте обработчик прерывания успевает отработать). Дополнительно добавил вывод служебной информации на бордюр (отображение режима видеоадаптера, нажатых клавиш "US","SS", режима "RUS/LAT"). Для этого сгенерирован дополнительный блок BROM памяти на 1Кб (ZROM) со знакогенератором (файл "zng.mif"), в который записан шрифт от "Радио-86РК". Эта функция также включается/отключается с помощью соответствующего "`define".

ОЗУ реализовано на микросхеме SRAM (необходимо минимум 64х8К). ОЗУ процессора и видеопамять (BRAM) записываются параллельно и независимо друг от друга. При этом чтение процессором происходит из своей памяти (SRAM), а чтение видеоконтроллера - из своей (BRAM). При этом не происходит никакого торможения процессора. Можно было реализовать и всю ОЗУ в виде BRAM памяти, но тогда пришлось бы использовать более ёмкую и дорогую FPGA.

Память загрузчика (ROM) реализована двумя способами (выбирается с помощью `define): 1 вариант - загрузчик записывается на SPI Flash, а при старте переписывается в SRAM; 2 вариант - загрузчик в сгенерированной BROM памяти. Также в качестве эксперимента я добавил поддержку расширенного загрузчика 8Кб (первая половина читается в окне памяти 0000h-0FFFh, вторая половина в 8000h-8FFFh). Выбирается также с помощью соответствующего "`define". Но расширенный загрузчик работает некорректно - почему-то перестаёт работать запись цвета в регистры палитры.

Ввод реализован с помощью обычной USB клавиатуры (через переходник на STM32F411CEU - платка BlackPill с кварцем на 25MHz) или можно использовать PS/2 клавиатуру (мой модуль работает некорректно, иногда залипают клавиши, поэтому он добавлен просто для ознакомления).

С загрузкой программ также есть несколько вариантов: 1 - реализован вход для магнитофона, который можно подключить к любому звуковоспроизводящему устройству через простейшую читалку на К561ЛН2 для спектрумоподобных компьютеров; 2 - записать образ ОЗУ (snapshot), созданный в эмуляторе Вектора со SPI Flash при начальном старте компьютера. Для этого также есть соответствующий "`define".

Звук я пока не реализовал. Хотя в проект и добавлен модуль К580ВИ53 (модуль взят из чужого проекта Вектора на DE1), но он не работает. Пока не разбирался, в чём причина.

Проект написан в среде Quartus Prime, имеет некоторые специфичные для Altera модули: Pll, блочная память, ALTDDIO (выходной буфер DDR для уменьшения частоты HDMI вдвое), которые необходимо синтезировать для FPGA других производителей.
